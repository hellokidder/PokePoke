## 请不要提交 Pull Request

这个仓库是**单向源码镜像**：所有改动都在内部开发仓里完成，然后按版本同步过来。
在这里合并的任何代码，都会在下一次发版时被覆盖。

**请改开一个 issue**，说明你遇到的问题或想要的行为 —— 我会在内部仓修好，随下一个版本发出来，
并在 CHANGELOG 里保留你的署名（如果是你提出/定位的）。

- 提 issue：https://github.com/hellokidder/PokePoke/issues/new

---

## Please open an issue instead

This repository is a **one-way source mirror**. Development happens in an internal repo and is
synced here at release boundaries — anything merged here is overwritten on the next release.

Please **open an issue** describing the bug or the behavior you want. It gets fixed internally
and ships with the next version, with credit in the CHANGELOG.

- Open an issue: https://github.com/hellokidder/PokePoke/issues/new
